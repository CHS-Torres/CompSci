# Centennial High School
## Business & Computer Science Industry Certification

This repository contains documentation and evidence supporting the Georgia Business & Computer Science Industry Certification process.

The site is organized by certification standard to make navigation easy for SHRM reviewers, administrators, advisory committee members, and teachers.

# Prompt Checklist (For Future Projects)

Use this checklist when asking for website changes so the result matches your intent faster.

- Goal: What should the final user experience feel like?
- Scope: Which folder/files can be edited?
- Layout: Required page structure (for example: sticky menu + one content panel)
- Navigation: Menu items, hover submenus, click behavior
- Default View: What page should load first?
- Content Source: Placeholder text, real text, or from README
- Style Rules: Simple/modern, mobile behavior, any color or font preferences
- Code Structure: Keep HTML/CSS/JS separated or any other constraints
- Avoid: What should not be added or changed
- Done Criteria: How to confirm the task is complete
